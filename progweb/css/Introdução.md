# 🎨 Anotações: introdução ao CSS

CSS é o que eu uso pra “dar cara” pro HTML (cores, fonte, espaçamento, layout…).

Anotação rápida:
- HTML = estrutura/conteúdo
- CSS = aparência/estilo

Coisas que sempre aparecem:
- **cascata** (ordem/importância das regras)
- **especificidade** (qual seletor “ganha” quando bate no mesmo elemento)
- seletores, pseudo-classes e pseudo-elementos
